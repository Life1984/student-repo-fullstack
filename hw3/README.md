## React tutorial

This implementation follows the completed example from the
[official React tic-tac-toe tutorial](https://react.dev/learn/tutorial-tic-tac-toe),
including its final cleanup step.

The tutorial's application code is saved as `react/src/App.jsx` for
compatibility with the project's Vite setup.

---

### Run the application

From the `hw3` directory, with Node.js 24 active:

```bash
npm run react
```

Open [http://localhost:5173](http://localhost:5173).

When using Babbage through SSH, forward port 5173 to your computer first.

Press Ctrl+C in the terminal to stop the server.

(The generated application is placed in `react/dist/`.)
